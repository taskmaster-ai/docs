## task-master parse-prd

Parses a PRD (Product Requirements Document) file and generates tasks for your project.

This command can either overwrite the existing `tasks.json` file or append new tasks, depending on the flags used. It supports research-backed task generation using Perplexity AI for more comprehensive breakdowns.

**Usage**
```bash
task-master parse-prd <prd-file.txt> [options]
```

**Flags**
| Flag                        | Description                                                                                  | Default                                 |
|-----------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------|
| `-i, --input <file>`        | Path to the PRD file (alternative to positional argument)                                    |                                         |
| `-o, --output <file>`       | Output file path                                                                             | `.taskmaster/tasks/tasks.json`          |
| `-n, --num-tasks <number>`  | Number of tasks to generate                                                                  | 10                                      |
| `-f, --force`               | Skip confirmation when overwriting existing tasks                                             |                                         |
| `--append`                  | Append new tasks to existing tasks.json instead of overwriting                               |                                         |
| `-r, --research`            | Use Perplexity AI for research-backed task generation, providing more comprehensive results  |                                         |
| `--tag <tag>`               | Specify tag context for task operations                                                      |                                         |

**Examples**
```bash
task-master parse-prd requirements.txt --num-tasks 15
task-master parse-prd --input=requirements.txt
task-master parse-prd --force
task-master parse-prd requirements_v2.txt --append
task-master parse-prd requirements.txt --research
# Using a tag for context
task-master parse-prd requirements.txt --tag=frontend
```

> **Note:**  
> - By default, this command looks for a PRD file at `.taskmaster/PRD.md`.
> - If you specify `--input` or a positional argument, that file is used instead.
> - Tasks are generated and either overwrite or append to `tasks.json` depending on the flags.

## task-master update

Updates multiple tasks with ID greater than or equal to the specified `--from` value, based on new information or implementation changes.

**Usage**
```bash
task-master update --from=<id> --prompt="<your prompt>" [options]
```

**Flags**
| Flag                        | Description                                                                                  | Default                                 |
|-----------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------|
| `-f, --file <file>`         | Path to the tasks file                                                                       | `.taskmaster/tasks/tasks.json`          |
| `--from <id>`               | Task ID to start updating from (tasks with ID >= this value will be updated)                 | 1                                       |
| `-p, --prompt <text>`       | Prompt explaining the changes or new context (required)                                      |                                         |
| `-r, --research`            | Use Perplexity AI for research-backed task updates                                           |                                         |
| `--tag <tag>`               | Specify tag context for task operations                                                      |                                         |

**Examples**
```bash
task-master update --from=5 --prompt="Update all tasks from 5 onward with new requirements"
task-master update --from=10 --prompt="Refactor for new API" --research
task-master update --from=1 --prompt="Add security notes" --tag=frontend
```

> **Note:**
> - The `--prompt` flag is required.
> - Use `update-task` for updating a single specific task.

Updates a single specific task by ID with new information. Use the `--id` flag to specify the task.

**Usage**
```bash
task-master update-task --id=<id> --prompt="<your prompt>" [options]
```

**Flags**
| Flag                        | Description                                                                                  | Default                                 |
|-----------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------|
| `-f, --file <file>`         | Path to the tasks file                                                                       | `.taskmaster/tasks/tasks.json`          |
| `-i, --id <id>`             | Task ID to update (required)                                                                 |                                         |
| `-p, --prompt <text>`       | Prompt explaining the changes or new context (required)                                      |                                         |
| `-r, --research`            | Use Perplexity AI for research-backed task updates                                           |                                         |
| `--append`                  | Append timestamped information to task details instead of full update                        |                                         |
| `--tag <tag>`               | Specify tag context for task operations                                                      |                                         |

**Examples**
```bash
task-master update-task --id=23 --prompt="Update with new information"
task-master update-task --id=7 --prompt="Add test coverage" --append
task-master update-task --id=15 --prompt="Refactor for new API" --research --tag=frontend
```

> **Note:**
> - The `--id` and `--prompt` flags are required.
> - Use `update` for updating multiple tasks at once.

## task-master expand

Expands a task into subtasks using AI, or expands all pending tasks based on complexity analysis.

**Usage**
```bash
task-master expand --id=<id> [options]
task-master expand --all [options]
```

**Flags**
| Flag                        | Description                                                                                  | Default                                 |
|-----------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------|
| `-i, --id <id>`             | ID of the task to expand                                                                     |                                         |
| `-a, --all`                 | Expand all pending tasks based on complexity analysis                                        |                                         |
| `-n, --num <number>`        | Number of subtasks to generate                                                               |                                         |
| `-r, --research`            | Enable research-backed generation (e.g., using Perplexity)                                  | false                                   |
| `-p, --prompt <text>`       | Additional context for subtask generation                                                    |                                         |
| `-f, --force`               | Force expansion even if subtasks exist                                                       | false                                   |
| `--file <file>`             | Path to the tasks file (relative to project root)                                            | `.taskmaster/tasks/tasks.json`          |
| `-cr, --complexity-report <file>` | Path to the report file                                                             | `.taskmaster/complexity-report.json`    |
| `--tag <tag>`               | Specify tag context for task operations                                                      |                                         |

**Examples**
```bash
task-master expand --id=5
task-master expand --all
task-master expand --id=3 --num=4 --prompt="Add more frontend details"
task-master expand --all --research --force --tag=frontend
```

> **Note:**
> - Use `--all` to expand all pending tasks.
> - Use `--force` to regenerate subtasks even if they already exist.

## task-master analyze-complexity

Analyzes tasks and generates expansion recommendations, optionally using research-backed analysis.

**Usage**
```bash
task-master analyze-complexity [options]
```

**Flags**
| Flag                        | Description                                                                                  | Default                                 |
|-----------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------|
| `-o, --output <file>`       | Output file path for the report                                                              |                                         |
| `-m, --model <model>`       | LLM model to use for analysis (defaults to configured model)                                 |                                         |
| `-t, --threshold <number>`  | Minimum complexity score to recommend expansion (1-10)                                       | 5                                       |
| `-f, --file <file>`         | Path to the tasks file                                                                       | `.taskmaster/tasks/tasks.json`          |
| `-r, --research`            | Use Perplexity AI for research-backed complexity analysis                                    |                                         |
| `-i, --id <ids>`            | Comma-separated list of specific task IDs to analyze                                         |                                         |
| `--from <id>`               | Starting task ID in a range to analyze                                                       |                                         |
| `--to <id>`                 | Ending task ID in a range to analyze                                                         |                                         |
| `--tag <tag>`               | Specify tag context for task operations                                                      |                                         |

**Examples**
```bash
task-master analyze-complexity --output=my-report.json
task-master analyze-complexity --model=claude-3-opus-20240229
task-master analyze-complexity --threshold=6 --file=custom-tasks.json
task-master analyze-complexity --research --tag=frontend
```

> **Note:**
> - The output report can be saved to a custom location with `--output`.
> - Use `--research` for research-backed complexity analysis.

## task-master research

Performs AI-powered research queries with project context, optionally saving results to tasks or files.

**Usage**
```bash
task-master research "<prompt>" [options]
```

**Flags**
| Flag                        | Description                                                                                  | Default                                 |
|-----------------------------|----------------------------------------------------------------------------------------------|-----------------------------------------|
| `--file <file>`             | Path to the tasks file                                                                       |                                         |
| `-i, --id <ids>`            | Comma-separated task/subtask IDs to include as context (e.g., "15,16.2")                   |                                         |
| `-f, --files <paths>`       | Comma-separated file paths to include as context                                             |                                         |
| `-c, --context <text>`      | Additional custom context to include in the research prompt                                  |                                         |
| `-t, --tree`                | Include project file tree structure in the research context                                  |                                         |
| `-s, --save <file>`         | Save research results to the specified task/subtask(s)                                       |                                         |
| `-d, --detail <level>`      | Output detail level: low, medium, high                                                       | medium                                  |
| `--save-to <id>`            | Automatically save research results to specified task/subtask ID (e.g., "15" or "15.2")   |                                         |
| `--save-file`               | Save research results to .taskmaster/docs/research/ directory                                |                                         |
| `--tag <tag>`               | Specify tag context for task operations                                                      |                                         |

**Examples**
```bash
task-master research "How should I implement user authentication?"
task-master research "What's the best approach?" --id=15,23.2
task-master research "How does auth work?" --files=src/auth.js --tree
task-master research "Implementation steps?" --save-to=15.2 --detail=high --tag=frontend
```

> **Note:**
> - The prompt is required.
> - Use `--save-to` or `--save-file` to save results to tasks or files.

## task-master add-tag

Creates a new tag context for organizing tasks. You can copy tasks from the current tag, another tag, or create a tag from the current git branch.

**Usage**
```bash
task-master add-tag <tagName> [options]
task-master add-tag --from-branch [options]
```

**Flags**
| Flag                        | Description                                                      | Default                                 |
|-----------------------------|------------------------------------------------------------------|-----------------------------------------|
| `-f, --file <file>`         | Path to the tasks file                                           | `.taskmaster/tasks/tasks.json`          |
| `--copy-from-current`       | Copy tasks from the current tag to the new tag                   |                                         |
| `--copy-from <tag>`         | Copy tasks from the specified tag to the new tag                 |                                         |
| `--from-branch`             | Create tag name from current git branch (ignores tagName)        |                                         |
| `-d, --description <text>`  | Optional description for the tag                                 |                                         |

**Examples**
```bash
task-master add-tag feature-xyz
# Copy from current tag
task-master add-tag feature-xyz --copy-from-current
# Copy from another tag
task-master add-tag feature-xyz --copy-from master
# Create tag from git branch
task-master add-tag --from-branch
```

> **Note:**
> - Either `tagName` or `--from-branch` is required.
> - Use `--copy-from-current` or `--copy-from` to duplicate tasks from another tag.
