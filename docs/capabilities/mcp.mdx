## parse_prd

**Description:**
Parse a Product Requirements Document (PRD) text file to automatically generate initial tasks. Reinitializing the project is not necessary to run this tool. It is recommended to run parse-prd after initializing the project and creating/importing a prd.txt file in the project root's .taskmaster/docs directory.

**Required Parameters**
| Name         | Type     | Description                                  |
|--------------|----------|----------------------------------------------|
| projectRoot  | string   | The directory of the project. Must be an absolute path. |

**Optional Parameters**
| Name         | Type     | Description                                  | Default      |
|--------------|----------|----------------------------------------------|--------------|
| input        | string   | Absolute path to the PRD document file (.txt, .md, etc.) | .taskmaster/docs/PRD.md |
| tag          | string   | Tag context to operate on                    |              |
| output       | string   | Output path for tasks.json file              | .taskmaster/tasks/tasks.json |
| numTasks     | string   | Approximate number of top-level tasks to generate (default: 10). Setting to 0 lets Taskmaster determine the number. Avoid numbers above 50. |              |
| force        | boolean  | Overwrite existing output file without prompting. | false        |
| research     | boolean  | Enable Taskmaster to use the research role for more informed task generation. Requires appropriate API key. |              |
| append       | boolean  | Append generated tasks to existing file.     |              |

**Example**
```console
Parse my PRD in /path/to/PRD.txt into 15 tasks with the tag API. Research best practices beforehand.
```
